* css
** Coments in css
We =/*= to start a comment and =*/= to close a comment.
** Selectors
A css rule always start with a selector. Lets say we want to style a certain item of the page, like =h1=:

#+BEGIN_SRC css
  h1{
      color: blue;
      text-align: center;
      font-size: 20px;
  }
#+END_SRC

Above code all together is called css rule.

=Note: Inline css shouldn't be used.= 
** In file style css

We can create <style> </style> tag to style properties inside a html file.

#+BEGIN_SRC html
  <style>
    h1{
    color: blue;
    }
  </style>
#+END_SRC

We generally don't want to add .css code in html file.

Instead we add all .css code inside a .css file. like style.css

=How to connect .css file to .html file?=

We can this file from .hmtl file with
#+BEGIN_SRC css
<link href="style.css" rel="stylesheet"/>
#+END_SRC

** List Selectors - Reusable code
Lets say we have below .css. One thing that is noticable is use reused same code again again.

Instead we can define once and use again.

#+BEGIN_SRC css

h1{
    font-size: 26px;
    font-family: sans-serif;
    text-transform: uppercase;
    font-style: italic;
}

h2{
    font-size: 40;
    font-family: sans-serif;
}

h3{
    font-size: 30px;
    font-family: sans-serif;
}

h4{
    font-size: 20px;
    font-family: sans-serif;
    text-transform: uppercase;
    text-align: center;
}

p{
    font-size: 22px;
    font-family: sans-serif;
    line-height: 1.5;
}

li{
    font-size: 20px;
    font-family: sans-serif;
}
#+END_SRC

Lets say if we want to change fonts. We need to change them in each and every part of the .css files. Instead we can do below:

#+BEGIN_SRC css
  ;;a list
  h1, h2, h3, h4, p, li{
      font-family: sans-serif;
  }

  ;;a list
  h1{
      font-size: 26px;
      text-transform: uppercase;
      font-style: italic;
  }

  h2{
      font-size: 40;
  }

  h3{
      font-size: 30px;
  }

  h4{
      font-size: 20px;
      text-transform: uppercase;
      text-align: center;
  }

  p{
      font-size: 22px;
      line-height: 1.5;
  }

  li{
      font-size: 20px;
  }
#+END_SRC

Now we can change the font at some location and it will reflect everywhere.

** ID on elements

=NOTE: We can use id only once!=

So instead of using:

#+BEGIN_SRC html

** Colors with css
*** RGB (Red Green Blue)

Read this link for [[https://www.davemorrowphotography.com/color-theory-photography][color theory]]

RGB model: Every color can be represented by a combination of RED, GREEN, BLUE.

Each of the 3 base colors can take a value between 0 and 255, which leads to 16.8 million diffrent colors.

So if we want complete RED color, it will be RED in complete maximum 255 and other colors at 0. Example: R(255), G(0), B(0).

Same for other colors too. If we want complete color of one kind, give it 255 and others 0.

White: All the Red, Green, Blue at maximum of 255.
When all colors in all 3 channels are the same, we get a grey color. So all numbers must be same: rgb(0,0,0) / #000000 / #000 This will be black. rgb(69, 69, 69) / #444444 / #444 this is more grey. rgb(183, 183, 183) / #b7b7b7 This is more lighter grey.

Other complementary colors will have mix of 2 colors. Ex: Yellow: Red(255), Green(255), Blue(0).

We define colors 2 ways in css:
- RGB/RGBA Notation
- Hexadecimal Notation

What is GRB with transparency ("alpha")?
RGB with Alpha is RGB with transparency. Ex: rgba (0, 255, 255, 0.3)

Hexadecimal notation:
Instead of using a scale from 0 to 255, we go from 0 to ff (255 in hexadecimal numbers). Ex: #00ffff (this can be also shorthand to #0ff)
  
*** Border

Lets say we have a selector named aside in the html file and we want to style it in the css. =border= is special property that takes 3 different keywords.

#+BEGIN_SRC css
aside{
    background-color: #f7f7f7f;
    border: 5px solid #1098ad;
}
#+END_SRC

This will put border all along the aside property. If we just want a border on one side we can define it too:

#+BEGIN_SRC css
aside{
    background-color: #f7f7f7f;
    border-top: 5px solid #1098ad;
}
#+END_SRC

** Pseudo classes
We can style items of ordered or unordered lists.

#+BEGIN_SRC css
li:first-child {
    font-weight: bold;
}

li:last-child{
    font-style: italic;
}

/* Select specific number of item */
li:nth-child(3){
    color: red;
}

/* You can even style even or odd items.
li:nth-child(even){
    color: blue;
}
*/
#+END_SRC
